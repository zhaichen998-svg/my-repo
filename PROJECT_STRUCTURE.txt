Key Features
============

Architecture:
  - ResNet-50 backbone (pre-trained on ImageNet)
  - PSPNet with Pyramid Pooling (1×1, 2×2, 3×3, 6×6)
  - SFEM with learnable coefficients (α, β)
  - Cosine similarity-based feature matching
  - Hierarchical integration (4×4 coarse + 8×8 fine pooling)

Training:
  - Meta-learning with episode generation
  - AdamW optimizer (lr=0.0001, weight_decay=0.0001)
  - Step decay (γ=0.5 every 50 epochs)
  - 500 iterations/epoch × 150 epochs
  - TensorBoard monitoring
  - Automatic checkpointing

Testing:
  - 8 comprehensive unit tests
  - Demo with synthetic data
  - Usage examples
  - Full verification suite

Documentation:
  - Architecture overview
  - Training guide with tips
  - Implementation summary
  - Example code
